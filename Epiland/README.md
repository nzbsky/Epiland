EPILAND Bot — це інтерактивний Telegram-чатбот для парку розваг, який допомагає користувачам:
- обрати парк (світ)
- переглянути розваги
- дізнатися ціни
- спланувати відпочинок
- забронювати святкування (демо)
- отримати персональні рекомендації

Проєкт орієнтований на створення максимально зручного та “живого” користувацького досвіду.

---

Бот працює за принципом:
- чітка логіка (без перевантаження AI)
- швидкі відповіді
- структуровані дані (SQL)
- мінімальне використання AI (тільки для розпізнавання намірів)
